# Ritmo — plano de 5 km

Uma página responsiva com o conteúdo de [treino.md](docs/treino.md). Abra `index.html` diretamente no navegador: a página, os estilos e os dados do treino são locais e não precisam de conexão. O progresso é salvo no armazenamento local do navegador, quando disponível, e não é compartilhado entre dispositivos ou navegadores.

Para alterar os estilos Tailwind, instale as dependências com `npm install` e execute `npm run build`. O comando atualiza `styles.css`, que deve permanecer junto de `index.html` e `app.js` para o uso offline.
